# Cleanup pass, 2026-10-01

*Written at the user's request: "a comprehensive review and iteration on this repo: streamline the logic, cut off unproductive branches, … comprehensive documentation of things removed as well as retained and refactored."*

This is the inventory. It lists what this pass removed, what it deliberately kept and why, what it refactored, and the decisions it leaves to the owner. It also gathers the earlier removals (2026-09-26 to 2026-10-01) in one table, so a single document answers "where did X go?".

## How the pass was run

1. **Four read-only audits** ran in parallel; their raw outputs are not committed:
   - `src/` reachability, using a TypeScript import graph whose entries are routes, workers, checks and anything imported by `scripts/`, `tools/` or `examples/`;
   - the flag table against the killed-experiment record;
   - orphans in `scripts/` and `tools/`;
   - documentation drift.
2. **Peers were consulted before any deletion.** Five other parallel workstreams were editing the same tree, and each sent a keep-list. Those lists overrode the audits wherever the two disagreed (see [Audit false positives](#audit-false-positives)).
3. **Rule for research artefacts:** protocols, reports, result summaries and the scripts that produced them **stay**. Regenerable per-photo intermediates of killed programmes **go**. Anything removed can be recovered from git.
4. **Landing:** only this pass's own hunks were committed, after a clean-clone `tsc` against HEAD. The deletions landed before the repo-wide SPDX header sweep (748b16e) so the two would not conflict.
