# Wave 5 plan: Swiss signature on the luma frontier (2026-10-02)

Coordinator: session `mt-image-72`. The plan was drafted and critiqued with Opus. Implementation and review are done by Sonnet agents, one git worktree and one `wave5/<id>` branch per stream. Cook mode applies (see [batch-ledger.md](batch-ledger.md)): no browser runs, and every landed stream gets a ledger row for the coordinator's consolidated pass.

## Starting point (research, 2026-10-01 evening)

- **Infrastructure is done.** deck.gl on WebGPU is the default, the luma `GPUCommandGraph` is the only compute path, and every GPU path with a CPU twin is on by default. Vendored luma is level with upstream master.
- **The look is not.** The best looks (terroir, hatch, sketch ridges, glow, waves, wind) are opt-in, and the default photo overlay is Classic with hue-ramp stripe contours. Swiss-map fidelity lives only in the Gipfelbuch sheet system and the landeskarte example. The app chrome still uses bordered cards, gradients, coloured shadows and fonts from the Google CDN.
- **Already built, so not redone:**
  - `relief.mode: "swiss"`: MDOW, generalised normal, curvature, warm/cool tones.
  - Slope-driven rock hatch and scree: `terroir/hatch.ts`.
  - luma #3318 sketch edges: `look/sketch-ridges.ts`, `LOOK_INK`.
  - CR-11: fixed in fec0515.
- **Browser debt.** Nothing from 10-01 has been checked in a browser. Wave 5 adds to that on purpose and is closed by one batched pass.

## Goals

1. **Swiss signature by default:** Imhof relief, index contours, Landeskarte hachures, swisstopo typography, a colour-blind-safe colour grammar, and one paper/ink chrome with self-hosted fonts.
2. **Bleeding edge on luma WebGPU:** a WGSL permutation compile gate on Dawn, subgroup fast paths, GPU skyline cost images, batched peak-snap gathers, a render-bundle spike, and later f16/rg11b10 targets.
3. **Trust:** publication blockers, code-review backlog items, and a node-run certified-stage gate tool.

## Wave 2 (after wave 1 lands)

- **A5 "Landeskarte" signature:** evolve the `swiss` preset with Imhof relief, index contours instead of the Classic stripes, ink ridges, hatch v2 where a pack exists, and swisstopo labels. Then flip the default as a separate commit, so the batch pass can revert it on its own.
- **C2:** mips on the GPU and GPU-resident mosaics for the horizon march.
- **f16 and `rg11b10ufloat` render targets** to cut VRAM. Both features are requested but unused.
- **Biome warnings to zero** (the coordinator does this after the merge).

## Deferred or dropped

- **Deferred:** Berann plan-oblique bending. It breaks the cull bounds, geo-query, picking and depth, and none of that can be verified without a browser. The aerial-perspective part may fold into A1.
- **Dropped:** the B5 sketch outline (already built); the upload-format change in GPU decode (stale premise).
- **Out of scope:** decisions that belong to the user: the eval set (N3/N5), the imagery licence default, the picker default, the Step Inside beta, and porting /roll to WebGPU.

## Rules

- **Shared files:** only the coordinator merges `scripts/ci/checks.mjs`, CHANGELOG, `package.json`, the route tree, the status and roadmap docs, and the batch ledger.
- **Additive-only files:** streams may only add to style types/schema/defaults, flags, `deck-webgpu/engine.ts` and `deck/terrain-layer.ts`.
- **Default output:** opt-in looks stay byte-identical when off, CPU twins stay, and `?gpu=off` keeps working.
- **Accuracy:** no accuracy-affecting default changes except a parity-gated `skylineGpu` flip. Dev split only.
- **Landing order:** B1 → B4 → C and D → A1–A3 → B3, B2, S1 → wave 2.
